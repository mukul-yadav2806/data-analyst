🚆 Just built a Railway Ticket Booking System from scratch — and learned a ton along the way!

Tech stack: 🐍 Python 🎈 Streamlit for an interactive web UI 🐘 PostgreSQL for the database 🔐 bcrypt for secure password hashing

Features: ✅ User login & signup ✅ Live trains listing ✅ Book tickets with passenger details saved to the database ✅ View & cancel bookings

Built this step by step to really understand how the pieces connect — database design, authentication logic, and a clean interactive UI, all working together in one project.
